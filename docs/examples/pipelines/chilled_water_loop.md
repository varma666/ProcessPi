# Chilled Water Loop with Branches & AHUs

**Problem**

Design and simulate a chilled water loop with:  

- Central pump and chiller  
- Main distribution header  
- 5 branch lines, each feeding 5 AHUs (Air Handling Units) in series  
- Return headers combining flow back to the expansion tank  

Demonstrates handling **large network topologies**, fixed diameters, and multiple equipment elements.

The network is built with `add_node` and `add_edge`, so the engine solves it as a graph: the flow in each edge comes from the mass balance at the nodes, and the five branches between `Main_Out` and `Return_Header` share the flow so that the pressure drop is the same through each of them (four loops). The closed circuit is opened at the tank: `Tank` (the pump suction) is the inlet node, the only node no edge enters, and `Return_Tank` is the outlet node, the only node no edge leaves. The governing drop from `Tank` to `Return_Tank` is then the drop around the whole circuit, pump included.

## Code

```python
from processpi.pipelines.engine import PipelineEngine
from processpi.pipelines.pipes import Pipe
from processpi.pipelines.network import PipelineNetwork
from processpi.pipelines.pumps import Pump
from processpi.pipelines.vessel import Vessel
from processpi.pipelines.equipment import Equipment
from processpi.units import *
from processpi.components import Water

# ---------------- Create Network ----------------
net = PipelineNetwork("Chilled Water Loop")

# ---------------- Nodes ----------------
net.add_node("Tank", elevation=0)           # tank outlet: the inlet node
net.add_node("Pump_In", elevation=0)
net.add_node("Pump_Out", elevation=1)
net.add_node("Chiller_Out", elevation=1)
net.add_node("Main_In", elevation=1)
net.add_node("Main_Out", elevation=1)

# Branch and AHU nodes
for b in range(1, 6):
    net.add_node(f"Branch_{b}_In", elevation=1)
    for a in range(1, 6):
        net.add_node(f"AHU_{b}_{a}_PipeOut", elevation=1)
        net.add_node(f"AHU_{b}_{a}_EqOut", elevation=1)
    net.add_node(f"Return_{b}", elevation=0)

net.add_node("Return_Header", elevation=0)
net.add_node("Return_Tank", elevation=0)    # tank return: the outlet node

# ---------------- Components ----------------
pump = Pump(
    name="Pump1",
    pump_type="Centrifugal",
    inlet_pressure=Pressure(101325, "Pa"),
    outlet_pressure=Pressure(201325, "Pa")
)

vessel = Vessel("ExpansionTank")
chiller = Equipment("Chiller", pressure_drop=0.2)

# ---------------- Build Network ----------------
# Tank → Pump → Chiller
net.add_edge(Pipe("TankPipe", length=Length(5, "m")), "Tank", "Pump_In")
net.add_edge(pump, "Pump_In", "Pump_Out")
net.add_edge(chiller, "Pump_Out", "Chiller_Out")

# Chiller → Main header
net.add_edge(Pipe("MainPipe", length=Length(15, "m")), "Chiller_Out", "Main_In")
net.add_edge(Pipe("MainPipe_Out", length=Length(5, "m")), "Main_In", "Main_Out")

# Branch inlets
for b in range(1, 6):
    net.add_edge(Pipe(f"MainToBranch_{b}", length=Length(3, "m")), "Main_Out", f"Branch_{b}_In")

# ---------------- AHU pipes (fixed diameters) ----------------
ahu_diameters = [Diameter(3, "in"), Diameter(4, "in"), Diameter(4, "in"),
                 Diameter(5, "in"), Diameter(6, "in")]
ahu_flows = [VolumetricFlowRate(8, "m3/h"), VolumetricFlowRate(10, "m3/h"),
             VolumetricFlowRate(10, "m3/h"), VolumetricFlowRate(12, "m3/h"),
             VolumetricFlowRate(15, "m3/h")]

for b in range(1, 6):
    for a in range(1, 6):
        dia = ahu_diameters[(a - 1) % len(ahu_diameters)]
        in_node = f"Branch_{b}_In" if a == 1 else f"AHU_{b}_{a-1}_EqOut"
        pipe_out = f"AHU_{b}_{a}_PipeOut"
        eq_out = f"AHU_{b}_{a}_EqOut"

        # Pipe
        net.add_edge(Pipe(f"AHUPipe_{b}_{a}", nominal_diameter=dia, length=Length(5, "m")), in_node, pipe_out)

        # AHU equipment
        pd = 0.05 + 0.01 * (ahu_flows[(a - 1) % len(ahu_flows)].to("m3/h").value / 10)
        net.add_edge(Equipment(f"AHU_{b}_{a}", pressure_drop=pd), pipe_out, eq_out)

# Branch returns
for b in range(1, 6):
    last_ahu_out = f"AHU_{b}_5_EqOut"
    net.add_edge(Pipe(f"BranchReturnPipe_{b}", length=Length(5, "m")), last_ahu_out, f"Return_{b}")

# Returns → Return header → Expansion tank
for b in range(1, 6):
    net.add_edge(Pipe(f"ReturnPipe_{b}", length=Length(10, "m")), f"Return_{b}", "Return_Header")
net.add_edge(vessel, "Return_Header", "Return_Tank")

# ---------------- Fluid & Flow ----------------
fluid = Water(temperature=Temperature(10, "C"), pressure=Pressure(101325, "Pa"))
flow_rate = VolumetricFlowRate(300, "m3/h")

# ---------------- Engine ----------------
model = PipelineEngine()
model.fit(fluid=fluid, flow_rate=flow_rate, network=net)
results = model.run()

# ---------------- Results ----------------
results.summary()
results.detailed_summary()
```

## Reading the results

- Each branch carries 60 m3/h (300 m3/h over five equal branches), so the 3 in AHU pipes run at 3.50 m/s and the branch pipes are sized for 60 m3/h (5 in, 1.29 m/s). Before the graph solve every pipe carried the full 300 m3/h: the 3 in AHU pipes ran at 17.48 m/s and the total drop was 1439.81 kPa.
- The pressure drop column is the start pressure minus the end pressure of each edge, static head included: the branch return pipes fall 1 m and gain 9.80 kPa, and the pump row is its 100 kPa gain less the 1 m it lifts the water.
- The circuit loses 61.51 kPa (6.27 m of water at 10 C). The pump's 1 bar is 38.49 kPa more than that, so the drop from `Tank` to `Return_Tank` is -38.49 kPa. The summary's Total Pressure Drop, Head Loss and Power Required cannot show a net rise, so they read 0; the governing outlet line and `results.results["summary"]["total_pressure_drop_Pa"]` keep the sign.
