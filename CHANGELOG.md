# Changelog

All notable changes to ProcessPI are documented here.

## [0.2.2] - 2026-11-10

### Added
- Tabular heat-exchanger datasheet results through the heat-exchanger result interface.
- Structured heat-exchanger result data for programmatic access.
- Heat-exchanger datasheet export support, including stream and hydraulic performance information.

### Improved
- Heat-exchanger datasheet presentation, including specification metadata and engineering-unit formatting.
- Heat-exchanger tube-side assignment and datasheet specification reporting.

### Tests
- Added tests for tabular heat-exchanger result output.

### Notes
- This release focuses on heat-exchanger results and datasheet reporting.
- Engineering calculations remain subject to validation against independent, appropriate design methods and project-specific engineering review.
